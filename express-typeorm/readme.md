## Guide Express TypeORM
1. Init
```bash
npm init -y
```
2. Install dependency / package
```bash
npm i express typeorm pg reflect-metadata nodemon
```

3. Buat index.js

4. package.json tambahkn command "dev" : "nodemon index.js" di bagian script
- Supaya akit cukup menjalankan command 
```bash
npm run dev
```

4. Buat Directory entity
   - membuat struktur / mode dari database (table berserta nama kolomnya)
  
5. buat ormconfig.js
